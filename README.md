## Publish FREE with GitHub Pages
1. Create a free account at https://github.com/
2. Create a new **public** repository, e.g. `jilnesh-rithu-wedding`.
3. Upload **everything inside this folder** (keep the `images` folder).
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will give you a free link similar to:
   `https://YOUR-USERNAME.github.io/jilnesh-rithu-wedding/`
8. Send that link through WhatsApp.

The website does not require paid hosting or a paid domain.
